# Stream Pro PH

Static GitHub Pages version of the Stream Pro PH subscription website.

## Upload to your repository

1. Extract this ZIP.
2. Upload all extracted files to the root of `BL4K3-Zelda/Stream-Pro-PH`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main`, choose `/ (root)`, and save.

GitHub will publish the site at a URL similar to:

`https://bl4k3-zelda.github.io/Stream-Pro-PH/`

## Edit the website

- `index.html` — wording and page sections
- `styles.css` — colors, spacing, and responsive design
- `script.js` — services, prices, calculator, and interactions

The customer order button opens the existing Stream Pro PH Google Form. Gmail notifications and renewal reminders remain managed by the Google Sheet and Apps Script.

## Security

Do not add passwords, API keys, payment credentials, or private customer data to this repository—especially if it is public.
